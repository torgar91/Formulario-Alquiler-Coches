# Formulario-Alquiler-Coches
Formulario interactivo de alquiler de coches con validación progresiva y cálculo automático en JavaScript. 
Aplicación web interactiva para una empresa de alquiler de coches, desarrollada con HTML, CSS y JavaScript puro.
El formulario valida si el usuario es mayor de edad y tiene carnet de conducir, solicita los datos necesarios y calcula automáticamente el coste total del alquiler según los días indicados.
El diseño es responsive y el código está organizado con clases CSS y funciones reutilizables para mantener una estructura profesional y clara.

🛠️ Tecnologías utilizadas:
HTML5 semántico

CSS3 con clases reutilizables (.mensaje-ok, .mensaje-error, etc.)

JavaScript nativo (sin librerías)

GitHub Pages para la publicación

🚀 Funcionalidades clave:
Validación progresiva por edad y carnet

Inputs dinámicos según las respuestas

Cálculo automático del coste (25€/día o tarifa semanal de 150€)

Visualización del resumen con estilo limpio y profesional

Responsive (adaptado a escritorio y móvil)
